# 录音分账核定台（Flask + SQLite）

资料员在录音分账入仓前，用本系统按单号维护申报，核定最少需要退回哪几份申报，
才能让整个结算期的份额全部可供数；确认后发布整份核定版，原申报留档。

数仓冲销或重载分账数据后，资料员还可在核定版页按回执号上传 CSV 验收，
核对仓里实际留下的份额是否与核定值一致。

## 业务规则

- 每首录音最多 **12 单**申报；按单号录入或更正，每单含一首录音、
  起止日（**含起日、不含止日**）和各权利人的**整数万分比**，单内合计须为 10000。
- 申报只能**整单保留 / 整单退回**。
- 保留单据中，同一权利人同日同值只计一次；同一人同日出现异值，
  或当天去重后份额之和不等于 10000，则当天无法供数。
- 结算期内任一天无保留单据覆盖，同样无法供数。
- **按区间核算，不逐日展开**：用相关申报的起止日把结算期切成基本段，逐段校验。
- 目标是退回最少的单据；多个方案退单数相同时，按单号字典序取最小保留集。
- 预览后可继续更正申报；确认时重新计算资料指纹，与预览不一致则要求重算。
- 只有确认成功才发布核定版（同录音同结算期版本号递增），原申报与更正历史均留档。
- 无解或写入失败时不产生新版，同一录音、同一结算期的上一版仍可取数
  （页面 + JSON API）。

## 仓数据验收（核定版页 → 验收入口）

- 按回执号上传 CSV，每行：类型（入仓 / 冲销）、权利人、整数万分比、起止日
  （含起日、不含止日）。回执号可写在 CSV 每行，也可填在表单（两者都填须一致）。
  表头支持中文（`回执号,类型,权利人,万分比,起日,止日`）或等价英文别名；
  也接受 5 列无表头 CSV（类型,权利人,万分比,起日,止日）。
- **同号同内容只计一次**（行序、空白不影响判定）；**同号异内容报冲突**，不入账。
- 入仓 +1、冲销 -1，按「权利人 + 万分比 + 日期区间」记入**净额区间表**。
  只有同一权利人同日同值的入仓与冲销才相抵；冲销可先于入仓回执到达。
- 新回执只拆分 / 更新其涉及的权利人、值及日期区间，**不重放历史回执**。
- 核对把净额区间边界与核定版分段边界合并切段，**按区间扫描、不逐日展开**；
  每段要求核定值中的「权利人 + 万分比」净条数为 1、其余值为 0，
  完全相符才显示**验收通过**。后到的回执造成差异时立即收回通过标记。
- 回执与核对结果在**同一事务**中生效：要么一起入账并重算，要么整体回滚，
  可用同一回执号重传，原核对结果照常可查。
- 写事务采用 `BEGIN IMMEDIATE` + `busy_timeout`，不同回执并发入账不漏计；
  并发同号同内容只入账一次。文件解析在入账事务之外进行，
  解析期间仍可提交其他回执。
- 仓数据按「录音 + 结算期」留存：发布新核定版时沿用同一份实际入账，
  并按新版核定值重新核对，各版通过标记同步收回 / 恢复。

## 启动（Docker Compose）

```bash
docker compose up --build
# 打开 http://localhost:8000
```

容器启动时自动建表，并在数据库为空时灌入三套演示数据（幂等，可重复启动）。
SQLite 数据保存在命名卷 `settlement-data`（容器内 `/data/settlement.db`）。

## 本地运行（无 Docker 时）

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export APP_DB=$(pwd)/data/settlement.db
flask --app wsgi:app init-db
flask --app wsgi:app seed        # 可选：演示数据
flask --app wsgi:app run --debug  # 或 gunicorn --bind 0.0.0.0:8000 wsgi:app
```

## 演示路径

1. **深夜电台（可核定）**：对 2026-01-01 ~ 2026-07-01 预览，最少退回 1 单
   （D003 与 D001 在重叠期对“甲”给出异值），D001/D004 同值去重；确认发布 v1。
2. 预览页可勾选“模拟写入失败”，确认后事务回滚、不新增版本，上一版仍可取数。
3. 更正 D001 后再点旧预览的“确认”，会被指纹校验拦下并提示重新预览；
   重新预览确认后发布 v2，旧申报版本在更正页留档可查。
4. **清晨钟声（无解·回退上一版）**：两单之间存在覆盖空档，预览给出无解诊断，
   禁止发布；预置的历史核定版仍可在“核定版取数”页面/JSON 取用。
5. **午后回廊（版本递增演示）**：重复同值申报同日只计一次。
6. **仓数据验收**：进入任一核定版的「验收入口」，可下载入仓 / 冲销 / 补仓
   样例 CSV 直接演示：
   1. 先只传冲销样例 → 差异列出、未通过（演示冲销先于入仓到达）；
   2. 再传入仓样例 → 与冲销相抵后**验收通过**；
   3. 回执页重复上传同号同内容 → 提示未重复计入；改内容再传 → 报冲突；
   4. 再传一份异值（如 甲=5500）入仓 → 差异重现、通过标记收回；
   5. 勾选「模拟写入失败」上传 → 回执与核对整体回滚，原结果仍可查，
      同一回执号可直接重传。

## 自测

```bash
python -I tests/selftest.py
```

覆盖：同值去重、异值/合计/无覆盖判失败、最少退单与字典序平手规则、
区间切分（不逐日展开）、录入校验、12 单上限、预览-确认指纹一致性拦截、
版本递增、写入失败回滚、无解禁发与上一版取数，以及验收相关的
CSV 解析校验、回执去重 / 冲突、冲销先到与相抵、异值不相抵、按区间核对、
解析期间并发提交、并发入账不漏计、写入失败重传、跨版本沿用仓数据等。

## 目录结构

```
app/
  __init__.py        应用工厂、CLI、模板过滤器
  engine.py          纯函数核定算法（切段、校验、最少退单求解）
  db.py              SQLite 表结构、申报/快照/版本仓储、回执与验收仓储、资料指纹
  acceptance.py      回执 CSV 解析、净额区间入账、按区间核对
  web.py             Flask 路由与表单校验
  seed.py            演示数据
  templates/ static/ 页面
tests/selftest.py    算法 + 端到端自测
Dockerfile / entrypoint.sh / docker-compose.yml
```
